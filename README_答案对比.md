## 🔍 最可能的差异原因

根据我的分析，以下是最可能导致答案不一致的原因：

### 问题三：

#### ⭐⭐⭐⭐⭐ 配对样本选择不同
```
您的方法：使用了5对配对（包括重复的纳入股票）
1. 2600 ↔ 2552
2. 2600 ↔ 2888      ← 2600重复使用
3. 301236 ↔ 300596
4. 601825 ↔ 601288
5. 601825 ↔ 601988  ← 601825重复使用

可能的不同：去除重复纳入股票，只保留3对
1. 2600 ↔ 2552
2. 301236 ↔ 300596
3. 601825 ↔ 601288

影响：配对数不同 → 收益率显著不同
```

#### ⭐⭐⭐⭐ 停牌处理方式不同
```
您的方法：停牌配对当天不参与计算，其他配对等权重平均

可能的不同：
- 停牌视为0收益
- 完全排除有停牌的配对

影响：组合收益计算结果不同
```

### 问题四：

#### ⭐⭐⭐⭐⭐ 配对数量不统一
```
您的方法：三个时期都使用5对配对

可能的不同：使用所有可用配对
- 牛市：12对（或去重后的数量）
- 非牛熊市：8对（或去重后的数量）
- 熊市：7对（或去重后的数量）

影响：
1. 收益率数值不同
2. 三个时期无法公平对比
```
