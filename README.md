## 核心计算公式

### 1. 超额收益率
```
Abret = Dretwd - Beta × Dretwdos
```
其中：
- Dretwd：个股日收益率
- Beta：个股系统风险系数
- Dretwdos：市场收益率（沪深300指数）

### 2. 配对组收益
```
配对收益 = 纳入股票收益 - 匹配股票收益
```

### 3. 组合收益
```
组合收益 = Σ(配对收益) / 有效配对数
```
（停牌的配对组不参与当天计算）
